# ♡ Наши дни — календарь-сердце

Красивый адаптивный календарь с **12 августа 2026 года по 20 августа 2027 года** — всего **374 дня**.

## Что умеет сайт
- Все 374 дня складываются в большое сердце.
- Каждый день можно зачеркнуть или снять отметку нажатием.
- Есть удобный календарь с переключением месяцев — особенно для телефона.
- Отметки сохраняются автоматически в `localStorage` **отдельно в каждом браузере на каждом устройстве**.
- Счётчик, процент и визуальный индикатор отмеченных дней.
- Экспорт и восстановление отметок через JSON-копию для переноса между телефонами.
- Без базы данных, входа, сторонних скриптов, сборщиков и рекламы.

**Важное замечание:** отметки не синхронизируются между телефонами и не хранятся в GitHub. Очистка данных браузера может стереть отметки — для сохранности можно выгрузить копию.

## Публикация на GitHub Pages

После включения Pages адрес сайта будет:

**https://bourlead-cynisc.github.io/love/**

1. Откройте [Settings → Pages](https://github.com/bourlead-cynisc/love/settings/pages).
2. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
3. Выберите **Branch: main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь появления опубликованной ссылки в разделе Pages.

Сайт статический: стартовый файл — `index.html`, никакие дополнительные сборки и сервисы не нужны.

## Файлы
